# credit-card：信用卡管理工具

在終端機管理自己的多張信用卡：

- **結帳日／繳款截止日**：設定每月幾號結帳、幾號繳款，自動算出每一期的日期（31 號遇到小月會自動以月底計算）。
- **最低應繳金額**：依「應繳總額 × 比例（預設 10%），且不低於下限（預設 $1,000）」試算，前期未繳足的最低應繳會累加到本期；也可直接輸入銀行帳單上的實際金額。
- **欠款追蹤**：已出帳未繳、未出帳消費、未到期分期、總欠款與可用額度一目了然。
- **提醒**：列出即將截止或已逾期的帳單，以及即將結帳的卡片。

只需要 Python 3.10 以上，不需要安裝任何第三方套件；資料存在本機的 SQLite 檔案。

## 安裝

```bash
pip install -e .
```

安裝後即可使用 `ccm` 指令。不安裝也可以在專案目錄下用 `python3 -m creditcard` 代替 `ccm`。

資料預設存放在 `~/.credit-card/cards.db`，可用環境變數 `CREDIT_CARD_DB` 或 `--db` 參數指定其他位置。備份時直接複製這個檔案即可。

## 快速開始

```bash
# 1. 新增卡片：每月 25 日結帳、9 日繳款截止，額度 10 萬
ccm card add 國泰CUBE --bank 國泰世華 --last4 1234 -s 25 -d 9 --limit 100000

# 2. 如果手上已經有一張還沒繳的帳單，輸入銀行帳單上的金額
ccm stmt set 國泰CUBE 2026-10-25 --balance 12345 --min 1235

# 3. 之後每次刷卡就記一筆
ccm txn add 國泰CUBE 2655 晚餐 -c 餐飲
ccm txn add 國泰CUBE 300 退貨 --refund

# 4. 分期付款：36,000 元分 12 期
ccm inst add 國泰CUBE 36000 12 iPhone --start-date 2026-08-10

# 5. 繳款
ccm pay add 國泰CUBE 5000
ccm pay add 國泰CUBE --min    # 繳足最低應繳
ccm pay add 國泰CUBE --full   # 繳清本期

# 6. 查看
ccm                   # 所有卡片總覽
ccm upcoming          # 未來 7 天的繳款／結帳提醒
ccm card show 國泰CUBE  # 單張卡片詳情、未出帳明細、分期進度
ccm stmt list 國泰CUBE  # 歷期帳單
```

## 指令一覽

| 指令 | 說明 |
| --- | --- |
| `ccm` / `ccm summary` | 所有卡片總覽 |
| `ccm upcoming [--days N]` | 未來 N 天（預設 7）內的繳款、結帳提醒與逾期警示 |
| `ccm card add NAME -s 結帳日 -d 繳款日 [--bank] [--last4] [--limit] [--min-rate] [--min-floor] [--note]` | 新增卡片 |
| `ccm card list` | 列出卡片 |
| `ccm card show CARD` | 單張卡片詳情 |
| `ccm card edit CARD [...]` | 修改卡片設定（選項同 add，另有 `--name`） |
| `ccm card remove CARD [-y]` | 刪除卡片與其所有紀錄 |
| `ccm txn add CARD 金額 [說明] [--date] [-c 類別] [--refund]` | 記錄消費（退款用 `--refund` 或負數） |
| `ccm txn list [--card] [--from] [--to] [-n]` | 列出消費 |
| `ccm txn remove ID` | 刪除消費 |
| `ccm pay add CARD [金額 \| --full \| --min] [--date] [--note]` | 記錄繳款 |
| `ccm pay list [--card] [--from] [--to] [-n]` | 列出繳款 |
| `ccm pay remove ID` | 刪除繳款 |
| `ccm inst add CARD 總額 期數 [說明] [--start-date]` | 新增分期，每月自動入帳一期 |
| `ccm inst list [--card] [--all]` | 列出分期進度 |
| `ccm inst remove ID` | 刪除分期 |
| `ccm stmt list CARD [-n]` | 歷期帳單 |
| `ccm stmt set CARD 結帳日 [--balance] [--min]` | 以銀行帳單實際金額覆蓋試算 |
| `ccm stmt unset CARD 結帳日` | 移除手動帳單金額，改回試算 |

`CARD` 可以是卡片名稱或 ID。全域選項 `--db`、`--today` 要放在指令前面，例如 `ccm --today 2026-12-01 upcoming` 可以試算某一天的狀況。

## 計算規則

- **帳單週期**：上一個結帳日的隔天 ～ 本次結帳日（含）。結帳日當天仍屬於進行中的週期，隔天才算出帳。
- **繳款截止日**：結帳日之後第一個「每月繳款日」。例如 25 日結帳、9 日繳款 → 10/25 結帳的帳單在 11/9 截止。
- **本期應繳總額** = 上期應繳總額 − 週期內的繳款 + 週期內的新增消費（含分期入帳、退款）。
- **最低應繳金額** = max(應繳總額 × 比例，下限)，無條件進位到元；應繳總額低於下限時須全額繳清；上期最低應繳沒繳足的差額會加到本期。
- **已繳金額**：該期結帳日之後到下一個結帳日（含）之間的繳款。
- **狀態**：免繳／待繳／已繳最低／已繳清／逾期（截止日後仍未繳足最低應繳）。
- **總欠款** = 目前帳上欠款（已出帳未繳 + 未出帳消費）+ 尚未入帳的分期金額；**可用額度** = 信用額度 − 總欠款。
- **分期**：每期金額取整數元，餘數併入第一期；從 `--start-date` 起每月同一天入帳一期。

> 各銀行的最低應繳算法（例如預借現金、利息、手續費的計算方式）不盡相同，程式的數字是試算值。
> 收到帳單後建議用 `ccm stmt set` 輸入實際的「本期應繳總額」與「最低應繳金額」，之後各期會以此為基礎接續計算。
> 目前不計算循環利息與違約金；若帳單上有這些費用，以 `stmt set` 輸入的實際金額為準。

## 開發

```bash
python3 -m unittest discover -s tests -v
```

程式結構：

| 檔案 | 內容 |
| --- | --- |
| `creditcard/dates.py` | 結帳日、繳款日等日期計算 |
| `creditcard/money.py` | 金額解析與格式化（內部以「分」為單位的整數儲存） |
| `creditcard/models.py` | 卡片、消費、繳款、分期、手動帳單的資料模型 |
| `creditcard/billing.py` | 帳單試算、最低應繳、欠款彙總 |
| `creditcard/db.py` | SQLite 存取 |
| `creditcard/cli.py` | 命令列介面 |
